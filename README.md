# app-portal-resource

本仓库用于归档和发布多个独立 HTML 页面，作为资源索引与内容展示的集中存储库。

## 项目简介

`app-portal-resource` 是一个静态资源仓库，主要存放各类独立 HTML 页面。这些页面通常用于信息展示、工具导航、内容聚合等场景，不依赖于特定后端服务，可直接通过浏览器打开或部署至静态托管平台使用。

## 目录说明

```
app-portal-resource/
├── pages/          # 存放所有独立 HTML 页面
├── assets/         # 页面依赖的静态资源（CSS、JS、图片等）
└── README.md       # 本文件
```

- `pages/`：每个子目录或文件对应一个独立的页面项目，命名清晰，便于识别。
- `assets/`：公共资源文件，可按需引用。

## 页面归档说明

- 所有页面均为纯前端实现，无后端依赖。
- 页面之间相互独立，互不干扰，便于单独维护与更新。
- 归档的页面可能包含示例数据、占位内容或通用模板，请根据实际需求调整。

## 维护说明

- 欢迎提交 Issue 或 Pull Request 来补充、修正或优化页面内容。
- 新增页面时，请在 `pages/` 下创建独立目录，并附上必要的说明文件。
- 请勿在页面中嵌入任何指向具体商业网站或服务的链接，避免产生误导。
- 本仓库不提供任何形式的担保或技术支持，仅作为资源归档用途。

## 使用方式

1. 克隆或下载本仓库到本地。
2. 直接使用浏览器打开 `pages/` 下的 HTML 文件。
3. 或部署至任意静态文件服务器。
